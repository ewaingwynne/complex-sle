Request: "remove all instances of `sorry`", possibly copying from leobon12/lean-formalizations
(cloned at `~/ext-src/lean-formalizations`, commit 31e7483, Lean v4.34.0-rc2, Mathlib a4c8ef0,

bodies. The plain-text draft `review/approvals/drafts/MarkovOneDim.lean.txt` also contains one.

## Mechanism

- An external whose exact statement is proved becomes `SEALED`. Its ABI hash is unchanged. The
  prefix gains the provider import, and the module docstring drops "permanent `sorry`". The checker
  and `manifest_add.py` must learn this transition, which is orchestrator tooling. Providers live in
  `ComplexSLE/Internal/ExternalProofs/<Name>.lean` with export
  `ComplexSLE.Internal.ExternalProofs.<name>`, and import no `ComplexSLE.External` module.
- An external that no theorem consumes, or that a proof-route substitution makes unused, is
  deleted from `ComplexSLE/External/` and from the manifest. This is M9 option 2(a), now requested.
- Ported code lives at a mirrored path, `ComplexSLE/Infrastructure/Zipper/<upstream path>`. It keeps
  its upstream namespace, carries a provenance header and is converted to the module system. The
  upstream code is trimmed to what is needed.
